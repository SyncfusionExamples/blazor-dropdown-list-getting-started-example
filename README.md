# Getting Started with Blazor Dropdown List

A getting-started sample demonstrating how to integrate and use the [Blazor Dropdown List](https://www.syncfusion.com/blazor-components/blazor-dropdown-list) component in a Blazor Server application.

## Overview

This Blazor Server application showcases the fundamental features of the Blazor Dropdown List component. Learn how to bind data from JSON sources, customize popup dimensions, and configure essential properties. The sample includes practical examples that demonstrate real-world usage patterns.

## Features

- **[Templates](https://blazor.syncfusion.com/documentation/dropdown-list/templates/)** - Customize dropdown items and header content
- **[Data Binding](https://blazor.syncfusion.com/documentation/dropdown-list/data-binding/)** - Connect to APIs and databases
- **[Filtering](https://blazor.syncfusion.com/documentation/dropdown-list/filtering/)** - Implement search and filter capabilities
- **[Cascading](https://blazor.syncfusion.com/documentation/dropdown-list/cascading/)** - Create dependent dropdown lists
- **[Virtualization](https://blazor.syncfusion.com/documentation/dropdown-list/virtualization/)** - Handle large datasets efficiently

## Getting Started

### Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-dropdown-list-getting-started.git
cd GettingStartedSample
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
